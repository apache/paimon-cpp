Detailed Description

Optionally implemented by a FormatWriter that can produce the column statistics of the file it has finished from the metadata it still holds in memory.

The data file writers then take the statistics from it instead of reopening the file through FormatStatsExtractor to read them back.

It is implemented alongside FormatWriter rather than added to it, so FormatWriter keeps its ABI and format writers that do not implement it are unaffected.
