Detailed Description

A unit of work of a table-level full-text search, planned by FullTextScan and searched by FullTextRead, aligned with Java org.apache.paimon.table.source.FullTextSearchSplit.

Splits can be serialized, so that a search can be planned in one process and run in others. The encoding is specific to Paimon C++: Java Paimon serializes its splits with Java serialization, so there is no cross-language format to match.
