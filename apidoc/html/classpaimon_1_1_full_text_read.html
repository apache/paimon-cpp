Create one with FullTextSearchBuilder::NewFullTextRead().

Searches splits and returns the limit highest-scoring rows among the candidates that they return.

The result holds global row ids and iterates them in ascending order; pass it to ScanContextBuilder::SetGlobalIndexResult() to read the rows, whose scores the read returns in the _INDEX_SCORE field.

The splits are searched in parallel, and each one returns at most limit candidates, chosen by its index. Ties among the candidates are broken by ascending row id, but which of the rows tied at the limit-th score of a split become candidates is up to its index. A split ranks only its search row ranges, and with deletion vectors enabled only the rows that are live in the snapshot the splits were planned from; BM25 statistics still come from its whole index shard.

Parameters
splitsSplits planned by a FullTextScan of the same column, all from one snapshot.
Returns
The rows found, or an error if a split is invalid, its index files do not index the column of the latest schema (for example, after the column was replaced), or an index cannot be read.
