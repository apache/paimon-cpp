Detailed Description

Plans a table-level full-text search into splits, aligned with Java org.apache.paimon.table.source.FullTextScan.

Create one with FullTextSearchBuilder::NewFullTextScan().

virtual Result< std::shared_ptr< Plan > > paimon::FullTextScan::CreatePlan ( )
pure virtual

Plans the search on the latest snapshot or the one selected by scan.snapshot-id, scan.tag-name, scan.timestamp or scan.timestamp-millis.

A timestamp selects the latest snapshot at or before that time. Set at most one selector, consistent with scan.mode. Each plan resolves its tag or timestamp anew.

Each full-text shard assigned rows in the selected partitions becomes one split. For overlapping shards, the planner prefers an index on the searched column over one that carries it as an extra field. Ties are broken by index type, field IDs and shard range. A stored split carries single-field scalar indexes for its row filter only where those indexes intersect its assigned search ranges.

When a selected partition has a full-text index for the column, full and detail assign gaps in single-field index coverage to a RawFullTextSearchSplit. full checks all row ids below the snapshot's next row id. detail checks data files in the selected partitions. Raw and stored splits rank disjoint rows and can be read independently.

Returns
The plan, or an error for conflicting scan options, a missing snapshot or tag, or unreadable manifests. A missing full-text or lucene-fts backend returns NotImplemented.
