Detailed Description

Builds a table-level full-text search of a data-evolution table, aligned with Java org.apache.paimon.table.source.FullTextSearchBuilder.

It searches the global full-text indexes of one column and returns the highest-scoring rows:

FullTextSearchBuilder builder(table_path);
builder.SetQuery("content", R"({"match":{"query":"paimon lake"}})").SetLimit(10);
PAIMON_ASSIGN_OR_RAISE(std::shared_ptr<ScoredGlobalIndexResult> result,
builder.ExecuteLocal());
ScanContextBuilder scan_builder(table_path);
scan_builder.SetGlobalIndexResult(result);

ExecuteLocal() plans and searches in this process. To run them in different processes, plan with NewFullTextScan(), serialize the splits with FullTextSearchSplit::Serialize(), and search them with the NewFullTextRead() of a builder for the same table, column and query.

The row ids of the result refer to the snapshot the search was planned from, which FullTextScan::Plan::SnapshotId() returns. If the table may change in between, pin the data scan to it with scan.mode = from-snapshot and scan.snapshot-id, or with the same scan.tag-name for a search of a tag, as the tag may outlive the snapshot.
