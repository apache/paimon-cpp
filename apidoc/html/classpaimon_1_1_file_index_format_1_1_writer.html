◆ PayloadWriter

using paimon::FileIndexFormat::Writer::PayloadWriter = std::function<Result<bool>(OutputStream*)>

Writes one payload without closing the stream.

Returns false for an absent index (without writing bytes), or true after writing a non-empty payload. The borrowed stream reports positions relative to the start of this payload, starting at 0. The callback must not retain the stream.

Writes one index.

V1 buffers payloads; V2 writes them directly to the destination. An empty callback or a false result denotes an empty index (-1, 0). A true result indicates that a non-empty payload was written. Call Finish() after the last index. Payload failures are terminal.
