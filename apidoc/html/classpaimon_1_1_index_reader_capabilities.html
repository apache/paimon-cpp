virtual std::optional< double > paimon::IndexReaderCapabilities::EstimateSelectivity ( const std::shared_ptr< LeafPredicate > &  predicate) const
virtual

Estimates the fraction of this reader's indexed rows expected to match the predicate.

Returns a value in [0, 1], or std::nullopt if no estimate is available. Values outside [0, 1] are also treated as unknown by evaluators. Estimates only guide predicate execution order and must never exclude rows. The default implementation returns std::nullopt.
