◆ GetFileSystem()

std::shared_ptr< FileSystem > paimon::Table::GetFileSystem ( ) const
inline

Returns the file system the table was opened with, which serves the table's files.

A catalog that hands out per-table file systems opens a table with the one for that table; it is null when the opener had none.

◆ GetRootPath()

const std::string & paimon::Table::GetRootPath ( ) const
inline

Returns the root path of the table in its file system.

It is empty when the opener had no location for the table, which a mock in a test is one case of.

Result< std::string > paimon::Table::CurrentBranch ( ) const

Returns the branch the table was opened for, which its identifier carries; main when it names none or a spelling of it, which its managers are bound to.

A malformed object name that hides the branch is reported.
