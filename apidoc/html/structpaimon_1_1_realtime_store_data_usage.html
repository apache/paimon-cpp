Detailed Description

Current memory and row counts tracked by a RealtimeStore.

Row counts are physical stored rows. For primary-key stores they include old versions and delete records, rather than the rows visible after merge-on-read. A segment removed by AdvanceCommittedOffset is no longer included, even if an older read view still pins it.
