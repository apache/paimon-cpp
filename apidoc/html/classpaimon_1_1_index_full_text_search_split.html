Detailed Description

A split that searches the full-text index files of one index shard, aligned with Java org.apache.paimon.table.source.IndexFullTextSearchSplit.

When index shards overlap, the scan gives each row to one shard, so a split may rank only some rows of its shard: SearchRowRanges() lie within [RowRangeStart(), RowRangeEnd()], the physical range of the shard, which maps the shard-local row ids of the index to global ones.
