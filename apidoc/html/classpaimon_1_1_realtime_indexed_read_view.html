Detailed Description

Optional capability for precise real-time filtering and search.

Ordinary query reads do not require it. Each visible row in the requested range of the pinned snapshot must belong to exactly one source. Source offset ranges must not overlap, so data readers can use the same pinned view with source-local offset bounds.
